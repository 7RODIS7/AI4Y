# 🌐 Как редактировать переводы

## Быстрый способ (рекомендуется)

### Вариант 1: Редактировать `translations.json`

**Этот файл НЕ используется пока**, но вы можете редактировать его для удобства, а затем скопировать в `js/i18n.js`.

```json
{
  "ru": {
    "hero": {
      "titleA": "Ваш новый текст здесь"
    }
  }
}
```

### Вариант 2: Редактировать `js/i18n.js` напрямую

**Этот файл используется сейчас**. Откройте его и найдите нужную секцию:

```javascript
// Строка ~293 для русского языка
ru: {
  hero: {
    titleA: 'Ваш AI-партнер: меньше рутины — больше результата',
    // ...
  }
}
```

## 🔧 Как изменить конкретный текст

### Пример 1: Изменить заголовок Hero

**Файл:** `js/i18n.js`  
**Строка:** ~293 (русский) или ~24 (английский)

```javascript
// Найдите:
hero: {
  titleA: 'Ваш AI-партнер: меньше рутины — больше результата',
  
// Измените на:
hero: {
  titleA: 'Ваш новый заголовок',
```

**Сохраните файл** → Обновите страницу в браузере

### Пример 2: Изменить текст кнопки

```javascript
// Найдите:
cta1: 'Получить бесплатную диагностику 20 мин',

// Измените на:
cta1: 'Записаться на консультацию',
```

### Пример 3: Изменить текст в карточке услуг

```javascript
// Найдите:
services: {
  item1: {
    title: 'Исследование и подбор инструментов',
    text: 'Помогаем исследовать рынок AI-инструментов...'
  }
}

// Измените нужное:
services: {
  item1: {
    title: 'Новое название',
    text: 'Новое описание'
  }
}
```

## 🎯 Быстрый поиск

### Как найти нужный текст?

1. **Откройте страницу** в браузере
2. **F12** → Console
3. **Найдите элемент** с текстом на странице
4. **Посмотрите атрибут** `data-i18n`
5. **Найдите этот ключ** в `js/i18n.js`

**Пример:**

```html
<h1 data-i18n="hero.titleA">...</h1>
```

Это значит, текст находится в `i18n.js` под ключом `hero.titleA`.

### Или просто используйте поиск (Ctrl+F)

Откройте `js/i18n.js` и найдите текст, который хотите изменить.

## 🐛 Если что-то не работает

### Текст не меняется после редактирования

1. **Очистите кеш браузера** (Ctrl+Shift+Delete)
2. **Откройте в режиме инкогнито**
3. **Проверьте Console на ошибки** (F12)

### Текст сломался / кавычки

JavaScript требует экранирования:

```javascript
// ❌ Неправильно
text: 'Он сказал "привет"'

// ✅ Правильно
text: 'Он сказал \"привет\"'
// или
text: "Он сказал 'привет'"
```

### Перевод не применяется

Проверьте, что элемент в HTML имеет атрибут `data-i18n`:

```html
<!-- ✅ Правильно -->
<h1 data-i18n="hero.titleA">Текст</h1>

<!-- ❌ Неправильно (не переведётся) -->
<h1>Текст</h1>
```

## 🚀 Добавить новый язык

### 1. Добавьте переводы в `js/i18n.js`

```javascript
// После bg: { ... }, добавьте:

de: {  // Немецкий
  nav: {
    benefits: 'Vorteile',
    services: 'Dienstleistungen',
    // ... и т.д.
  },
  hero: {
    titleA: 'Ihr AI-Partner: Weniger Routine, mehr Ergebnisse',
    // ... и т.д.
  }
}
```

### 2. Добавьте кнопку в header (`index.html`)

```html
<div class="lang-switcher">
  <button class="lang-btn" data-lang="en" title="English">EN</button>
  <button class="lang-btn" data-lang="ru" title="Русский">RU</button>
  <button class="lang-btn" data-lang="bg" title="Български">BG</button>
  <button class="lang-btn" data-lang="de" title="Deutsch">DE</button> <!-- Новая -->
</div>
```

### 3. Готово!

Язык появится автоматически в меню.

---

## 💡 Советы

1. **Копируйте структуру** - убедитесь, что все ключи есть во всех языках
2. **Проверяйте длину** - некоторые языки длиннее (немецкий vs английский)
3. **Тестируйте на мобильном** - длинный текст может сломать layout
4. **Сохраняйте HTML теги** - если в тексте есть `<strong>`, оставьте их
